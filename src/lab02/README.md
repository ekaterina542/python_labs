## matrix
### 1) transpose(mat)
транспонирование матрицы. если матрица пустая - возврат пустой матрицы, если матрица рваная - ValueError. res - результирующая матрица, r - строка res. двойной цикл по каждому элементу матрицы, у элемента матрицы меняются индексы местами и добавляются в r, затем r добавляется в res

### 2) row_sums(mat)
сумма по каждой строке. если матрица пустая - возврат пустой матрицы, если матрица рваная - ValueError. res - результирующий список, цикл for по строкам матрицы, добавление суммы элементов строки в res

### 3) col_sums(mat)
сумма по каждому столбцу. если матрица рваная - ValueError. функция поочерёдно обрабатывает каждый столбец матрицы. для каждого столбца переменная t устанавливается в 0, после чего функция проходит по всем строкам и прибавляет к t элемент из текущего столбца. полученная сумма добавляется в список res. таким образом, после обработки всех столбцов в res находятся их суммы, которые функция возвращает в качестве результата.
