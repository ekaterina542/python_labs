## Задание А: реализация функций normalize, tokenize, count_freq, top_n

### Функция normalize
функция приводит текст к единому виду. если параметр yo2e равен True, она заменяет все буквы «ё» на «е», включая заглавные. затем, если casefold равен True, переводит текст в нижний регистр с помощью casefold(), иначе использует lower(). далее заменяет переносы строк, табуляцию на пробелы. убирает лишние пробелы в начале и конце текста, а также заменяет несколько пробелов подряд на один. возвращает обработанный текст.

### Функция tokenize
функция выделяет из текста отдельные слова с помощью регулярного выражения \w+(?:-\w+)*. оно позволяет находить последовательности букв, цифр и символов подчёркивания, в том числе слова, соединённые дефисом. функция re.finditer() находит все совпадения с заданным шаблоном. цикл проходит по найденным совпадениям и добавляет каждое слово в список l с помощью append(). в результате функция возвращает список найденных слов.

### Функция count_freq
функция подсчитывает частоту появления каждого слова в списке tokens. для хранения результатов используется словарь freq, где ключом является слово, а значением — количество его повторений. если слово уже присутствует в словаре, его значение увеличивается на единицу. если слова ещё нет, оно добавляется со значением 1. после подсчёта функция сортирует пары слов и их частот по алфавиту с помощью sorted(), а затем возвращает полученный результат в виде словаря.

### Функция top_n
функция выбирает n наиболее часто встречающихся слов из словаря freq. сначала пары «слово — частота» преобразуются в список words. затем список сортируется по убыванию частоты, а при одинаковой частоте — по алфавиту. для задания порядка сортировки используется выражение lambda x: (-x[1], x[0]), где x[1] — частота слова, а x[0] — само слово. в конце с помощью среза words[:n] выбираются первые n элементов, которые функция возвращает в виде списка кортежей.
