# ЛР6 — CLI‑утилиты с argparse (cat/grep‑lite + конвертеры)

## cli_text.py
### функция main()
функция создает интерфейс командной строки с помощью argparse. в ней задаются две подкоманды: cat для вывода содержимого файла и stats для анализа текста. для каждой команды указываются необходимые аргументы. после получения аргументов функция проверяет, какая команда была выбрана, и выполняет соответствующие действия.

### команда cat
команда открывает указанный файл в режиме чтения с кодировкой utf-8 и построчно выводит его содержимое. если указан флаг -n, перед каждой строкой выводится ее номер, начиная с 1. для чтения используется enumerate(), а параметр end="" позволяет избежать появления лишних переносов строк.
### команда stats
команда читает весь текст из указанного файла и передает его на обработку функциям лабораторной № 3. сначала текст приводится к единому виду с помощью normalize(), затем разбивается на слова с помощью tokenize(). функция count_freq() подсчитывает количество повторений каждого слова, а top_n() выбирает самые частые слова. в конце выводится общее количество слов, количество уникальных слов и список самых частых слов.

## cli_convert.py
### функция main()
функция создает интерфейс командной строки для конвертации файлов с помощью argparse. в ней задаются три подкоманды: json2csv, csv2json и csv2xlsx. для каждой подкоманды добавляются аргументы --in и --out, которые указывают путь к исходному файлу и путь, куда нужно сохранить результат. аргумент dest используется, чтобы сохранить значения в переменных args.input и args.output, так как in является зарезервированным словом в python.
после получения аргументов функция проверяет, какая подкоманда была выбрана. в зависимости от этого она вызывает соответствующую функцию из лабораторной № 5 и передает ей пути к файлам. после успешного выполнения конвертации выводится сообщение о результате.

### команда json2csv
команда преобразует данные из json-файла в csv-файл. она вызывает функцию json_to_csv(), передавая ей путь к исходному json-файлу и путь для сохранения csv-файла. функция конвертации считывает данные, определяет столбцы по ключам объектов и записывает их в табличном формате.

### команда csv2json
команда преобразует данные из csv-файла в json-файл. она вызывает функцию csv_to_json() и передает ей пути к исходному и выходному файлам. первая строка csv используется как заголовок, а остальные строки преобразуются в json-объекты. после выполнения конвертации выводится сообщение об успешном преобразовании.

### команда csv2xlsx
команда преобразует csv-файл в файл формата xlsx, который можно открыть в excel. она вызывает функцию csv_to_xlsx() и передает ей пути к исходному csv-файлу и выходному xlsx-файлу. данные из csv переносятся на лист excel, после чего файл сохраняется по указанному пути.
