# Лабораторная работа 4 - Файлы: TXT/CSV и отчёты по текстовой статистике

## Задание A — модуль src/lab04/io_txt_csv.py

### функция read_text()
читает текстовый файл в указанной кодировке и возвращает его содержимое в виде строки. параметр path указывает путь к файлу, который нужно прочитать, например "data/lab04/input.txt". путь можно передать в виде строки или объекта Path. параметр encoding задаёт кодировку файла, по умолчанию используется utf-8. если файл не найден или возникает ошибка при чтении текста, программа выдаёт соответствующее исключение. при необходимости можно указать другую кодировку, например cp1251.

### функция write_csv()
записывает переданные данные в CSV-файл - таблицу с разделителям и запятыми. параметр rows содержит данные, которые нужно записать. параметр path указывает путь и имя файла. параметр header позволяет указать заголовки столбцов, которые будут записаны в первую строку файла, например ("word", "count"). если заголовок не указан, запись начинается сразу с данных. параметр newline="" используется для корректной записи строк в CSV-файл, а encoding="utf-8" задаёт кодировку, которая позволяет сохранять русский текст. если файл уже существует, его содержимое перезаписывается.

## Задание В - скрипт src/lab04/text_report.py
скрипт предназначен для анализа текста и формирования отчёта о частоте слов. сначала программа считывает текст из входного файла. если файл не найден, всплывает ошибка. затем текст нормализуется и разбивается на отдельные слова с помощью функций из лабораторной работы № 3. после этого программа подсчитывает общее количество слов и количество уникальных слов. далее слова сортируются по убыванию частоты встречаемости, а при одинаковой частоте — по алфавиту. также формируется список из пяти самых частых слов. полученные данные сохраняются в файл report.csv с заголовками word и count. в конце программа выводит в консоль общее количество слов, количество уникальных слов и список пяти самых частых слов.
